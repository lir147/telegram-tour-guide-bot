# Telegram Tour Guide

Telegram-бот для самостоятельных экскурсий. Каталог маршрутов, последовательные остановки с описаниями и фотографиями, навигация и сохранение прогресса в SQLite.

## Запуск

Требуется Python 3.11+.

1. Создайте бота через @BotFather.
2. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN` и числовые Telegram ID администраторов через запятую в `ADMIN_IDS`.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Запустите `python bot.py`.

## Команды

- `/start`, `/tours` — каталог экскурсий.
- `/admin` — справка администратора.
- `/addtour Прогулка по городу` — создание маршрута.
- `/tourids` — список ID маршрутов.
- `/addstop 1 | Центральная площадь | Начало маршрута | https://example.com/photo.jpg` — добавление остановки. URL фото необязателен; используйте действительную ссылку или Telegram file_id.

Маршруты первоначально отсутствуют: добавьте свои данные через команды администратора. Прогресс хранится отдельно для каждого пользователя и маршрута.

## Docker

`docker build -t tour-guide .`

`docker run --rm --env-file .env -e DB_PATH=/data/tours.db -v tour-data:/data tour-guide`

Не публикуйте токен бота и файл `.env`.
